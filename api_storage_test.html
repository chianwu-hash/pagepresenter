測試項目

此頁面將測試 OpenAI API 模型選擇的儲存和讀取功能：

  • ✅ 檢查儲存機制是否正確
  • ✅ 檢查讀取機制是否正確
  • ✅ 檢查預設值是否正確
  • ✅ 檢查模型選擇是否同步

自動測試

點擊按鈕執行各項測試：

手動測試步驟

  1. 點擊瀏覽器右上角的擴充套件圖示
  2. 展開「OpenAI API 模型選擇」設定
  3. 嘗試選擇不同的模型選項
  4. 點擊「僅儲存模型選擇」按鈕
  5. 重新開啟擴充套件彈窗，確認模型選擇是否保持
  6. 在狀態區域檢查是否顯示正確的 API 設定資訊

預期結果

  • ✅ 模型選擇能正確儲存
  • ✅ 重新開啟後模型選擇保持不變
  • ✅ 狀態顯示包含 API 設定資訊
  • ✅ 預設模型為 gpt-4o-mini
