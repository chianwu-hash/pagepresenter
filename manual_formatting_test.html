📚 教學內容測試（仿照截圖內容）

國小五年級上學期 國語課教案 單元：當我們同在一起 課次：一 你我之間 總教學時間：7節 x 40分鐘 = 280分鐘（每週五天進行，週一、週四有兩節連上）一、單元與課程概述 本單元主題「當我們同在一起」旨在引導學生探討人際互動關係，認識自我與他人的獨特價值，並在協作中發揮彼此優勢。第一課「你我之間」透過日常生活中常見的物品作為意象，藉由簡潔的文字表達詩人對人與人「你我之間」互動的觀點，讓學生理解彼此的差異性與互補性，學習相互理解、尊重、寬容並以可接受的方式相處，同時在協力合作中看見對方的價值。一、教學目標認知方面：• 理解現代詩歌的特色與含意，並能連結生活事物進行想像。• 學察「你我之間」的差異性與互補性。• 理解課文中「人際相處」的智慧，包含尊重、寬容與合作的重要性。• 能讀懂課文內容、大意與主旨，並理解詩作的主題與象徵關係。• 認識本課生字詞的多音字、易錯發音及字形辨別，並了解字義和造詞。• 理解四段式記敘文的寫作結構與常用修辭手法。技能方面：• 能專心聆聽詩歌重點，並透過適當的表情、動作朗讀詩歌。• 運用語調、表情、肢體輔助口語表達詩歌內容。• 能運用部件掌握字音與字義，並掌握偏旁變化和間架結構書寫生字。• 能運用本課短語及句型進行仿寫與造句。• 能運用聯想途徑與轉折手法發展文章內容，習作四段式記敘文的寫作結構與常用修辭手法。

💻 技術文件測試

系統架構說明 一、前端架構 使用 React 18 作為主要框架，搭配 TypeScript 進行型別檢查。狀態管理採用 Redux Toolkit，路由管理使用 React Router v6。UI 組件庫選用 Material-UI，確保介面一致性與使用者體驗。二、後端架構 採用 Node.js 搭配 Express 框架建構 RESTful API。資料庫使用 PostgreSQL 儲存結構化資料，Redis 作為快取層提升查詢效能。身分驗證採用 JWT token 機制，確保 API 安全性。三、部署架構 使用 Docker 容器化應用程式，透過 Kubernetes 進行容器編排。CI/CD 流程使用 GitHub Actions，自動化測試與部署流程。監控系統採用 Prometheus + Grafana，即時監控系統效能與錯誤狀況。

學習目標 認知目標 • 理解程式設計的基本概念 • 掌握變數與資料型別的使用方法 • 學習條件判斷與迴圈控制結構 • 認識函數定義與呼叫的原理 技能目標 • 能夠撰寫簡單的程式碼 • 能夠除錯並修正程式錯誤 • 能夠使用開發工具進行程式編寫 • 能夠閱讀他人撰寫的程式碼 情意目標 • 培養邏輯思維能力 • 建立問題解決的態度 • 增進團隊合作的精神 • 養成持續學習的習慣 教學活動設計 第一階段：概念導入 透過生活實例介紹程式設計概念，讓學生了解程式在日常生活中的應用。使用簡單的流程圖說明程式執行的邏輯順序。第二階段：實作體驗 引導學生使用視覺化程式設計工具，如 Scratch，進行簡單的程式創作。讓學生體驗程式設計的樂趣，建立學習信心。第三階段：深度學習 介紹文字型程式語言，如 Python，教授基本語法與概念。透過實際專案練習，讓學生應用所學知識解決實際問題。

  • 沒有標題層次區分
  • 條列項目無法識別
  • 閱讀困難，像「文字牆」
  • 無法快速掌握內容結構

✅ 優化後效果

  • 智能分段，段落清晰
  • 標題自動識別並突出
  • 條列項目正確格式化
  • 教學內容特殊處理
  • 適合大螢幕閱讀的結構

🔍 測試檢查項目

標題識別測試

  • 「教學目標」、「課程規劃」等教學關鍵詞應被識別為標題
  • 「一、二、三、」序號應被正確識別為標題
  • 以冒號結尾的短語應被識別為子標題

分段效果測試

  • 長段落應被智能拆分為多個段落
  • 在句號、冒號等標點後應有適當分段
  • 不再出現超長的「文字牆」效果

條列項目測試

  • 「• 」、「‧」等符號開頭應被識別為條列
  • 「理解...」、「能夠...」等教學動詞開頭應被識別
  • 條列項目應有適當的縮排和格式
