🚀 AI 模型優先順序功能測試

新功能概述

已成功新增 AI 模型調用優先順序選擇功能，允許使用者自定義不同 AI 模型的調用順序。

✅ 已實現的功能

  • 拖拽排序界面：使用者可透過拖拽調整模型順序
  • 三種模型支援：Google Gemini、OpenAI GPT、離線排版
  • 動態調用邏輯：系統按照用戶設定的順序嘗試各個模型
  • 設定持久化：順序設定自動保存到 Chrome Storage
  • 錯誤降級機制：當前模型失敗時自動嘗試下一個

🧪 測試步驟

1 載入擴充功能
chrome://extensions/ → 重新載入網頁簡報器擴充功能
2 開啟優先順序設定

點擊擴充功能圖示 → 找到「🚀 AI 模型調用順序」區塊 → 點擊 ⚙️ 設定按鈕

3 測試拖拽排序

嘗試拖拽三個模型項目調整順序：

  • Google Gemini（免費額度 · 高品質處理 · 中文友好）
  • OpenAI GPT（高速處理 · 穩定可靠 · 多模型選擇）
  • 離線排版（離線處理 · 快速響應 · 基礎格式化）
4 驗證順序保存

調整順序後，重新開啟擴充功能彈出視窗，確認順序已保存。

🔍 檢查重點

UI 功能檢查
  • 拖拽排序是否平滑運作
  • 優先順序數字是否正確更新
  • 重設按鈕是否正常工作
  • 設定區塊的展開/收合功能
功能邏輯檢查
  • Storage 中的 modelPriority 設定是否正確保存
  • AI 調用是否按照設定的順序執行
  • 錯誤降級機制是否正常運作
  • Console 日誌是否清楚顯示處理流程

✅ 預期成果

完成測試後，使用者應該能夠：

  • 透過直觀的拖拽操作調整 AI 模型的優先順序
  • 系統依照設定順序智能調用不同的 AI 模型
  • 當某個模型無法使用時，自動降級到下一個可用模型
  • 享受更靈活和個人化的 AI 處理體驗

🛠️ 故障排除

常見問題

  • 拖拽無反應：檢查 JavaScript 錯誤，確認事件監聽器正確綁定
  • 順序未保存：檢查 Chrome Storage 權限，確認 storage API 可正常使用
  • 調用順序錯誤：檢查 content.js 中的 getModelPriority() 方法
  • 模型調用失敗：檢查 API 金鑰設定和網路連線

除錯方法

  • 開啟 Chrome 開發者工具查看 Console 日誌
  • 檢查 Application → Storage → Local Storage 中的設定值
  • 使用 chrome://extensions/ 查看擴充功能錯誤
