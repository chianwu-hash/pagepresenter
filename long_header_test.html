✅ 解決方案

調整檢查邏輯順序：強標題特徵優先於長度限制

  1. 最優先：檢查強標題特徵（中文序號、數字序號等）
  2. 直接返回：符合強標題特徵 → 立即 return true
  3. 不受影響：跳過長度限制和排除規則
  4. 保證一致：所有中文序號都能正確識別
