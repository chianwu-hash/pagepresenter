OpenAI API 整合說明

功能概述

本擴充套件現在支援多個 AI 服務提供商，包括 OpenAI 和 Google Gemini API。系統會按照優先級順序嘗試不同的 API 服務：

  1. OpenAI API - 優先使用，支援 GPT-4o Mini、GPT-4o、GPT-4、GPT-3.5 Turbo
  2. Google Gemini API - 備用選項，免費使用
  3. 規則式處理 - 最終備用方案，完全離線

API 配置

在擴充套件彈出視窗中，使用者可以分別配置：

  • OpenAI API 金鑰（格式：sk-開頭）
  • 模型選擇（推薦：GPT-4o Mini）
  • Gemini API 金鑰（備用方案）

成本效益分析

OpenAI GPT-4o Mini 具有以下優勢：

  • 每月 $5 免費額度（約150萬 tokens）
  • 處理速度比 Gemini 快約 2-3 倍
  • 中文處理品質優秀
  • API 穩定性高
