# 網頁簡報器 Chrome 擴充套件

專為會議室大螢幕展示設計的網頁閱讀優化工具。透過手動選取內容，確保展示內容的精確性。

## 功能特色

### 核心功能
- ✅ **手動選取內容**：完全由使用者控制要展示的內容
- ✅ **智能格式重整**：自動識別標題、段落、條列結構
- ✅ **85吋大螢幕適配**：字體大小和版面專為大螢幕優化
- ✅ **右鍵啟動**：選取文字後右鍵即可啟動簡報模式

### 顯示優化
- ✅ 字體放大/縮小控制（16-72px）
- ✅ 高對比模式（黑底白字）
- ✅ 行高調整最佳化
- ✅ 聚焦模式（淡化非當前段落）

### 導航功能
- ✅ 自動生成目錄導航
- ✅ 閱讀進度指示器
- ✅ 快速段落跳轉

### 操作支援
- ✅ 快捷鍵控制
- ✅ 全螢幕模式
- ✅ 設定自動記憶

## 安裝方式

1. 下載或克隆此專案到本地
2. 開啟 Chrome 瀏覽器
3. 進入 `chrome://extensions/`
4. 開啟「開發人員模式」
5. 點擊「載入未封裝項目」
6. 選擇專案資料夾

## 使用方法

### 主要操作流程
1. **選取內容**: 在網頁上用滑鼠選取要展示的文字內容
2. **啟動簡報**: 右鍵點擊選取文字 → 選擇「啟動簡報模式」
3. **調整設定**: 使用工具列按鈕調整字體大小、對比度等
4. **導航瀏覽**: 使用左側自動生成的目錄快速跳轉段落
5. **結束展示**: 點擊工具列「✕」按鈕或按Esc鍵

### 替代啟動方式
- **快速啟動**: 先選取文字，再點擊擴充套件圖示「快速啟動」按鈕
- **查看說明**: 不選取文字直接點擊圖示，會顯示使用說明

### 快捷鍵（簡報模式中）
- `Esc` - 關閉簡報模式
- `Ctrl++` - 放大字體
- `Ctrl+-` - 縮小字體
- `F11` - 全螢幕模式
- `↑/↓` - 上/下一段落

## 技術規格

### 相容性
- Chrome 版本 88 以上
- 支援所有網站 (需要內容存取權限)

### 權限說明
- `activeTab` - 存取當前分頁內容
- `storage` - 儲存使用者設定
- `contextMenus` - 在右鍵選單中添加「啟動簡報模式」選項
