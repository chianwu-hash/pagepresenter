# 網頁簡報器 Chrome 擴充套件

專為會議室大螢幕展示設計的網頁閱讀優化工具。ESA 會議管理與列印頁可自動擷取會議內容；其他網頁仍可透過手動選取精確控制展示範圍。

## 功能特色

### 核心功能
- ✅ **ESA 自動擷取**：會議管理與列印頁不必先選取即可啟動；卡片式會議頁只收錄有內容的黃色報告卡，排除簽到、簽收與閱覽管理卡，並重編合併後的目錄序號
- ✅ **AI 明確同意**：離線版完成後，只有使用者確認才會送往 AI
- ✅ **AI 重點建議**：Gemini 依會議語境產生保守的重點建議；結果不是標準答案，可隨時關閉
- ✅ **Gemini 背景呼叫**：API Key 由擴充功能背景層使用，透過 `x-goog-api-key` header 傳送，不交給內容腳本或放入請求 URL
- ✅ **手動選取內容**：有選取時一律以選取範圍為準
- ✅ **結構化離線版**：保留表格、連結、圖片與基本文字格式
- ✅ **ESA 附件卡片**：在所屬報告下顯示完整檔名與日期，點擊時沿用 ESA 原始開啟流程；附件資訊不自動送往 AI
- ✅ **保留原文重點**：離線版安全保留作者原有的紅字、底色、粗體與底線，可一鍵顯示或隱藏
- ✅ **智能格式重整**：自動識別標題、段落、條列結構
- ✅ **85吋大螢幕適配**：字體大小和版面專為大螢幕優化
- ✅ **右鍵啟動**：選取文字後右鍵即可啟動簡報模式

### 顯示優化
- ✅ 字體放大/縮小控制（16-72px）
- ✅ 高對比模式（黑底白字）
- ✅ 行高調整最佳化
- ✅ 聚焦模式（淡化非當前段落）

### 導航功能
- ✅ 自動生成目錄導航
- ✅ 閱讀進度指示器
- ✅ 快速段落跳轉

### 操作支援
- ✅ 快捷鍵控制
- ✅ 全螢幕模式
- ✅ 設定自動記憶

## 安裝方式

1. 下載或克隆此專案到本地
2. 開啟 Chrome 瀏覽器
3. 進入 `chrome://extensions/`
4. 開啟「開發人員模式」
5. 點擊「載入未封裝項目」
6. 選擇專案資料夾

## 使用方法

### 主要操作流程
1. **ESA 會議管理／列印頁**：直接點擊擴充套件的「啟動簡報模式」
2. **部分內容或其他網站**：先選取文字，再點擊擴充套件或使用右鍵選單
3. **調整設定**: 使用工具列按鈕調整字體大小、對比度等
4. **導航瀏覽**: 使用左側自動生成的目錄快速跳轉段落
5. **結束展示**: 點擊工具列「✕」按鈕或按Esc鍵

### 替代啟動方式
- **精確範圍**：即使在 ESA 頁面，只要先選取文字，就只處理該範圍
- **查看說明**：在非支援頁面且未選取文字時，顯示使用說明

### AI 版本與資料邊界

- 離線版會先完成；未經明確同意，不會把本次會議文字送往 AI。
- AI 原文整理版保留原始資訊，只改善結構並提供語意重點建議。
- AI 精簡版會濃縮內容並提供語意重點建議。
- AI 重點屬於可能被使用者接受的建議，不是唯一正確答案。
- 附件檔案本身不會自動上傳；免費層的資料使用方式與額度以 Google 當期政策為準。

### 快捷鍵（簡報模式中）
- `Esc` - 關閉簡報模式
- `Ctrl++` - 放大字體
- `Ctrl+-` - 縮小字體
- `F11` - 全螢幕模式
- `↑/↓` - 上/下一段落

## 檔案結構

```
webreader/
├── manifest.json       # 擴充套件設定檔
├── background.js       # 背景腳本（處理右鍵選單）
├── popup.html         # 彈出視窗介面
├── popup.js           # 彈出視窗邏輯
├── content.js         # 內容擷取、離線排版、AI處理與簡報控制
├── styles.css         # 簡報模式樣式
├── icons/            # 擴充套件圖示
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md         # 說明文件
```

## 技術規格

### 相容性
- Chrome 版本 88 以上
- 支援所有網站 (需要內容存取權限)

### 權限說明
- `activeTab` - 存取當前分頁內容
- `storage` - 儲存使用者設定
- `contextMenus` - 在右鍵選單中添加「啟動簡報模式」選項
